# Career_OS Application Policy v0.1

The objective is not maximum application volume. The objective is:

**high-quality applications × high relevance × high interview-conversion probability**

## Decision policy

- `PRIORITY_APPLY`: score 85–100 and Hard Gate `PASS`.
- `APPLY`: score 75–84 and Hard Gate `PASS`.
- `REVIEW`: score 65–74, or any `MANUAL_REVIEW` hard-gate result regardless of score.
- `SKIP`: score below 65, or any Hard Gate `FAIL` regardless of score.

A high score never overrides a failed mandatory condition. Automation cost is not a reason to apply.

An `Application_ID` is created only after explicit user approval or submission. Stage 3 does not create real applications, tailored resumes, cover letters, or portal activity.

One `Job_ID` may link to zero or one application. A duplicate application for the same job requires explicit approval and a controlled exception record.
